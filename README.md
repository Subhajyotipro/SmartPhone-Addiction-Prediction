# Smartphone Addiction Prediction – Machine Learning Model

## 📌 Overview
This project is a **Machine Learning model** designed to analyze user behavior patterns and predict the likelihood of **smartphone addiction**.  
The model uses behavioral and usage-related features to classify addiction risk based on collected data.

The goal of this project is to explore how data science and ML can help identify unhealthy smartphone usage patterns and support awareness or intervention strategies.

---

## 🎯 Objectives
- Analyze smartphone usage data
- Identify patterns linked to addictive behavior
- Train and evaluate a machine learning model for prediction
- Provide a reproducible ML workflow

---

## 🧠 Machine Learning Approach
The project follows a standard ML pipeline:

1. **Data Collection**
2. **Data Preprocessing**
   - Handling missing values
   - Encoding categorical variables
   - Feature scaling
3. **Exploratory Data Analysis (EDA)**
4. **Model Training**
5. **Model Evaluation**
6. **Prediction**

---

## 📊 Dataset
The dataset includes features such as:
- Screen time
- App usage frequency
- Social media usage
- Sleep patterns
- Daily smartphone interaction metrics

> ⚠️ Dataset used is for educational/research purposes only.
